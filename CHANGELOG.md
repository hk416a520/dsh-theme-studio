# Changelog

Notable changes to this plugin. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-11-05

### Added

- Left-sidebar entry and full-page appearance panel.
- RGB + opacity editing for 13 theme tokens, in separate light and dark palettes, with per-row and global reset.
- Background image read from a local file: client-side re-encode, cover/contain/tile fit, dim slider, preview and removal.
- Color-scheme row listing the built-in schemes plus every theme registered in the running client.
- Notice in the Colors section when a non-built-in theme is active, since the override layer stacks above it.
- English and Chinese copy, plugin icon, and `npm run check` for manifest, syntax, locale and icon validation.
